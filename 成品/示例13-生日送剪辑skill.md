# 示例 13 · 我生日,我送你一个礼物(生日特别篇 · 送口播剪辑 skill)

- **类型**:故事叙事 + 心态启发(混合型)｜ **时长**:约 85–95 秒
- **提词器版**:`成品/示例13-提词器.txt`
- **层级**:TOF 拉新 + 留言领取(特别篇:礼物本身就是内容)
- **语言**:马来西亚白话,不讲技术
- **发布**:生日那个月内

## 只用雷哥讲过的事实
- 这个月是雷哥生日。
- 初衷:提倡每一个人做个人 IP。
- AI 时代变得很快,唯一让自己不焦虑的方法是自修;学做个人 IP 短视频口播 → 自我提升、得到归宿、得到心安。
- 拍摄只要 5–10 分钟,剪辑才是很多人不会的。
- 准备了一个 skill:不用剪映、不用 CapCut,一个 ChatGPT 或 Claude,10 分钟做到精剪的效果。
- 故事:以前没有自信 → 在自媒体分享后,发现自己的能力可以帮到人 → 开始在自媒体、线上 Zoom、线下课程分享。
- 留言打 aigoal,就送这个 skill。

## 🎬 全稿(括号是拍摄提示;上提词器用 `.txt` 版)

**【开头 · 惊门:反常识】**(看镜头,笑一下)
这个月,我生日。
可是今年,不是你送我礼物——是我送你一个。
(停一秒)
**【悬念】**
这个礼物,可以帮你剪口播。
不过,我先讲,为什么要送这个。

**【故事 · 值符 + 生门天任:真实经历】**(放松,像跟朋友讲)
以前的我,其实没什么自信。
后来,我开始在自媒体分享。
分享着,分享着,我才发现——
(停,放慢)
原来我会的东西,真的可以帮到人。
(停一秒)
所以我越讲越多:
自媒体讲,线上 Zoom 讲,线下开课,也讲。

**【初衷 · 兑宫:开口】**(语气转稳,看镜头)
我的初衷很简单:
我希望,每一个人,都做自己的个人 IP。

**【为什么 · 心态反转】**(语速快一点,讲到"自修"慢下来)
这个时代,有了 AI,什么都变得很快。
快到很多人,都很焦虑。
(停)
要不焦虑,我觉得唯一的方法,就是自修。
学拍口播,就是自修。
因为你要讲给别人听,自己就要先想清楚。

**【升华 · 景门天英:修行感】**(一句比一句慢)
讲着讲着,你会提升自己;
你会找到归宿;
你的心,会安下来。

**【礼物 · 墓也是库:教学做成工具】**(语气轻快)
其实拍一条口播,只要五到十分钟。
难的,是剪辑。很多人,就是不会剪。
所以这次,我准备了一个 skill,教 AI 帮你剪。
不用剪映,不用 CapCut,也剪得出精剪的效果。
一个 ChatGPT,或者 Claude,十分钟,搞定。
(可选,真的用这个 skill 剪才讲:你现在看的这条,就是用它剪的。)

**【金句 · 震宫天冲】**(停两秒,放慢,看镜头)
剪辑,AI 可以帮你;
开口,要靠你自己。

**【领取 · 开门空亡:讲送,不讲卖】**(换回轻松,笑;画面打出大字 aigoal)
这个 skill,就当是我的生日礼物。
留言打 aigoal,我就送给你。

**【签名】**(停一秒,换回平常语气)
我是雷哥,不吹 AI——(停半秒)只讲真 AI。

## 3 个备选开头
1. ★ 这个月,我生日。可是今年,不是你送我礼物——是我送你一个。(反常识 + 好奇:送什么?)
2. 拍一条口播,只要五到十分钟。难的,是剪辑。(痛点:想拍又不会剪的人会停下来)

## ✂️ 剪辑要点
- 第一句就是"这个月,我生日",前面不要放任何东西。
- "原来我会的东西,真的可以帮到人"是整条的心:前后留停顿。
- "自媒体讲 / 线上 Zoom 讲 / 线下开课也讲"可以配三个画面,**只用真的照片或录屏**;没有就不放。
- "提升自己 / 找到归宿 / 心会安下来"一句比一句慢,不要剪太紧。
- 金句前停两秒,保留。
- 领取那句,画面打出大字 **aigoal**,观众才知道怎样拼。
- 字幕照雷哥讲的大马口语打,不要改成书面华语。

## 🔮 奇门设计说明
- **惊门(值使)**:第一句反常识——生日不是收礼,是送礼。
- **值符**:敢讲"以前的我,没什么自信"。坐 C 位的人,先敢认自己。
- **兑宫(口:教学、分享)**:故事主线就是"开口"——自媒体讲、Zoom 讲、线下课讲;金句也落在"开口"。
- **生门天任**:用真实经历打动人。只讲雷哥自己的转变,不加料。
- **杜门入墓 → 墓也是库**:定盘建议"把教学做成工具(skill)";这条就是把剪辑这一关做成 skill 送出去。
- **景门天英**:落点要有修行感——自修、归宿、心安。
- **震宫天冲**:前面平稳讲故事,最后突然一句"剪辑,AI 可以帮你;开口,要靠你自己"。
- **开门空亡**:讲"送",不讲"卖";不报价、不逼单。
- **时间**:2026 是表达输出年(抓紧 Q4),送 skill、带出 Zoom 和线下课,也是为 2027 课程变现年铺路;戊戌月(10/8 14:29 → 11/7)戊落命宫,利曝光。
