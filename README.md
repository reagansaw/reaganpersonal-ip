# 雷哥口播 IP 生成器

雷哥的个人 IP 口播文案系统。定位：做 AI 自动化营销（aigoal.ai），
但**道法自然、从不强推 AI**——帮你分清什么时候该用 AI、什么时候该用手。

## 目录

| 文件 | 作用 |
|---|---|
| `雷哥-人设与风格.md` | 灵魂文件：人设、道法自然心法、语感、慎用词 |
| `口播生成器.md` | 黄金 6 段结构 + 复制即用的生成 Prompt |
| `开头钩子库.md` | 30+ 开头，按类型分好，3 秒抓人 |
| `选题库.md` | 5 大支柱 × 50 选题 + 本周开机推荐 |
| `成品/` | 已完成、可直接拍的口播文案 |

## 怎么用（三步出一条）
1. 打开 `选题库.md`，挑一个选题。
2. 打开 `口播生成器.md`，把选题填进生成 Prompt，产出正文 + 3 个备选开头。
3. 对照 `雷哥-人设与风格.md` 的慎用词过一遍，满意就存进 `成品/`。

## 核心心法（一句话）
> 重复的交给 AI，判断的留给人。工具的事交给工具，人的事留给自己。
