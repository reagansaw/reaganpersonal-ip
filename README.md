# 雷哥口播 IP 生成器

雷哥的个人 IP 口播文案系统。定位:**带你看 AI 的"另一程"**——做 AI 自动化营销(aigoal.ai),
但从不迷信 AI。**AI 是壳,人性是核**:不讲 setting、不讲 prompt,只聊为什么用、值不值、用了人会变成什么样。道法自然,从不制造焦虑。

> 本系统融合了三层素材:**5 条爆款文案**(结构模板)+ **100 条开头钩子**(开头库)+ **2 份 IP 方法论**(底层理论)。

## 怎么用(三步出一条)
1. 打开 `选题库.md` 挑选题(或用「老问题+新情绪+强代入感」自造)。
2. 打开 `口播生成器.md`,先想清"说给谁听",再把选题填进生成 Prompt。
3. 对照 `开头钩子库` 换个好开头、`人设` 过一遍慎用词,满意就存进 `成品/`。

## 核心心法(一句话)
> 重复的交给 AI,判断的留给人。工具的事交给工具,人的事留给自己。

## 爆款的 6 条铁律(拆自你的样本)
1. 开头别自我介绍  2. 先接情绪再讲道理  3. 排比金句是命
4. 要有具体的人和场景  5. 认知反转  6. 升华金句收尾
