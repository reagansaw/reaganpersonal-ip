# 雷哥口播 IP 生成器

雷哥的个人 IP 口播文案系统。定位:做 AI 自动化营销(aigoal.ai),
但**道法自然、从不强推 AI**——帮你分清什么时候该用 AI、什么时候该用手。

> 本系统融合了三层素材:**5 条爆款文案**(结构模板)+ **100 条开头钩子**(开头库)+ **2 份 IP 方法论**(底层理论)。

## 目录

| 文件 | 作用 |
|---|---|
| `雷哥-人设与风格.md` | 灵魂文件:人设、IP 三层壁垒、稳定内核+流动外壳、慎用词 |
| `爆款拆解.md` | 5 条爆款拆成 5 大套路模板 + 排比金句公式 |
| `口播生成器.md` | 黄金 6 段结构 + 利他=有效给予 + 生成 Prompt + 验证清单 |
| `开头钩子库.md` | 32 个开头,按类型分好,已剔除叫卖味 |
| `选题库.md` | 爆款选题公式 + 5 支柱 × 50 选题 + 本周开机推荐 |
| `成品/` | 5 条已完成、可直接拍的口播(套路 A–E 各一条)|

## 怎么用(三步出一条)
1. 打开 `选题库.md` 挑选题(或用「老问题+新情绪+强代入感」自造)。
2. 打开 `口播生成器.md`,先想清"说给谁听",再把选题填进生成 Prompt。
3. 对照 `开头钩子库` 换个好开头、`人设` 过一遍慎用词,满意就存进 `成品/`。

## 核心心法(一句话)
> 重复的交给 AI,判断的留给人。工具的事交给工具,人的事留给自己。

## 爆款的 6 条铁律(拆自你的样本)
1. 开头别自我介绍  2. 先接情绪再讲道理  3. 排比金句是命
4. 要有具体的人和场景  5. 认知反转  6. 升华金句收尾
