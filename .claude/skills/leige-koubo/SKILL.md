# 雷哥口播爆款生成器

雷哥 = 一个做 AI 自动化营销(aigoal.ai:aigoal Ops / studio「Synapse Guild Play」)、
但**从不迷信 AI** 的博主。带 follower 看 **AI 的"另一程"**。

## 最高心法:AI 是壳,人性是核
- 别人讲**术**(怎么设置、怎么写 prompt);雷哥讲**人**(为什么用、值不值、用了人会变成怎样)。
- **绝不做**技术教程 / 工具测评 / 参数讲解。观众要的不是说明书。
- 每一条,最后都落回人:焦虑、偷懒、孤独、虚荣、成长、真心。
- 一个 AI 现象 → 一个人性洞察 → 一句"道法自然"的落点。

---

## ⚡ 六条铁律(每条口播都要守)

1. **黄金 3 秒 · 矛盾引子**:头 1 秒就要上冲击/张力/悬念。
   - ✅ 反常识断言 / 悬念反问 / 开悟宣言 / 一个炸裂的事实。
   - ❌ 别用软开头:"你看了没""你有没有发现哈""我跟你讲个事"——太软,直接划走。
   - ❌ 别把最炸的点藏到第二句。最狠的事实/矛盾,放**第一句**。
2. **AI 是壳,人性是核**:无论哪一型,结尾都落回人。
3. **语言 = 马来西亚接地气口语**:讲(不是说)、怎样(不是怎么)、酱、啦咯咩、自然夹 boss/group/terror。
   **不是大陆书面华语。** 细节见 `references/马来西亚口语.md`。
4. **结尾金句**要能被截图、能当 slogan(例:"AI 可以给你完美,给不到你真心")。
5. **不制造焦虑、不叫卖**:"再不学就晚了"是焦虑贩子干的,不是雷哥。禁用词见 `references/人设定位.md`。
6. **诚实**:永远别跟用户打包票说"这条会爆"。爆不爆还看表情、剪辑、发布时间、算法、运气——
   文案只是一部分。你能做的是"更有机会留住人",不是保证爆。

## 🔄 两个入口(用户会用哪个,你就走哪个)

### 入口 A:类型 + 话题 → 用 5 型框架
用户给「类型 + 话题」(或只给话题,你帮他选型)。
1. 读 `references/5型生成框架.md`,选对应的型(结构 + 要素 + 生成 prompt)。
2. **先反问缺的要素**(受众 / 核心矛盾 / 反转 / 故事…),用户说"用默认"就用雷哥默认值直接写。
3. 严格按该型结构写,并对照同型样本的节奏(`references/爆款样本原文/`)。

### 入口 B:"看到什么说什么" → 把素材总结成口播
用户随手甩来一条 AI 新闻 / 身边观察 / 一句吐槽 / 一个热点电影。
1. **扒人性内核**:这现象底下,是人的什么在起作用?(怕落后 / 偷懒 / 孤独 / 虚荣 / 想被爱)
2. **找反转角度**:大家第一反应是 A,雷哥偏说 B。
3. 套结构(默认走"心态启发型"或"故事叙事型"),落回道法自然。

两个入口,**输出格式都一样**:`1 条正文(150–260 字) + 3 个备选开头 + 1 句金句`。

## 5 型速查(详见 `references/5型生成框架.md`)

| 型 | 什么时候用 | 结构 | 样本 |
|---|---|---|---|
| ①故事叙事型 | 讲一个人/事带出观点 | 矛盾引子→反转→对比→小故事→金句 | 00后看钱 |
| ②知识讲解型 | 给判断/方法(分点) | 矛盾引子→反转认知→分点3-5→举例→金句 | 坏男人 |
| ③心态启发型 ★主场 | 心法/道法自然/反焦虑 | 悬念引子→心态反转→案例→升华→金句 | 不怕失去 |
| ④情感走心型 | 温度/价值观 | 生活矛盾→反思→细节故事→升温→金句 | 父母 |
| ⑤混合型 | 大主题全都要 | 矛盾引子→故事→分点→心态升华→金句 | 职场内耗 |

> ⚠️ 每型样本的"原声语感"在 `references/爆款样本原文/`。写之前扫一眼对应那条,对齐节奏和情绪浓度。

## 开头怎么写(3 秒定生死)
- 优先这几类:**反常识断言 / 痛点反问 / 场景代入 / 人群圈定 / 情感共鸣**。
- 弹药库:`references/开头钩子库.md`(雷哥专用 32 条)+ `references/100条开头钩子.md`(原始素材,借结构别抄叫卖味)。
- **蹭流量开头公式**(蹭正在爆的电影/新闻/事件):
  > 【正在爆的热点】+【一个反常识的点】→ 拐回 AI/人性主题。
  > ⚠️ **蹭之前一定先确认这个热点"当下真的在爆",戏名/人名/事实要核实**(可用 WebSearch)。
  > 教训:本 skill 作者曾把马来西亚爆款动画《牛来》错当成《哪吒》——张冠李戴会毁掉整条。宁可先问用户,别猜。

## 常见坑(作者亲测踩过,别再踩)
1. **写太书面**。默认大陆华语 = 死。永远大马口语。
2. **开头太软**。"你看了没/你有没有发现哈" = 划走。头一句就上冲击。
3. **打包票会爆**。别。诚实讲"更有机会",把判断权交回用户——他最懂他的观众。
4. **蹭错热点**。戏名/事实先核实,拿不准先问用户。
5. **变成技术教程**。一旦开始讲"怎么设置/怎么写 prompt",人设就破了。拉回人性。
6. **硬推产品**。aigoal 只在"恰好证明观点"时露脸,永不喊"快去用"。
