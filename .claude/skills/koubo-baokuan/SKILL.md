# 通用口播爆款生成器（学生版）

一套能给**任何赛道**用的短视频口播框架。核心不是"套模板",是**先想清楚人性,再讲**。

## ▶ 第一步:设定人设(第一次用必做)
读 `references/人设设定模板.md`,让创作者填 6 个空:
**身份 / 赛道 / 帮谁 / 核心反差 / 语言风格 / 签名结尾**。
- 已经填过 → 直接用他的人设写。
- 没填 → **先请他填这 6 个空**(或给个方向),别用空泛的"通用人设"硬写,那样出来的口播没有"人味"。

> 填好的人设 = 这个 skill 的"灵魂"。之后每条口播都照它来。

---

## ⚡ 六条铁律(任何赛道都要守)

1. **黄金 3 秒 · 矛盾引子**:头 1 秒就上冲击/张力/悬念。最狠的事实放**第一句**。
   - ✅ 反常识断言 / 悬念反问 / 开悟宣言 / 一个炸裂事实 / 圈定人群。
   - ❌ 软开头:"你看了没""你有没有发现哈""我跟你讲个事"——直接划走。
2. **要有一个"核"**:每条最后都落回**人性**(焦虑、偷懒、孤独、虚荣、想被爱、成长),别停在"讲道理/教方法"。
3. **语言 = 创作者自己的口语**(见人设第 5 空)。默认可用马来西亚接地气口语(`references/马来西亚口语.md`)。**别写书面腔。**
4. **结尾金句**要能被截图、能当 slogan。
5. **不制造焦虑、不叫卖、不硬推**。"再不学就晚了"这种焦虑贩子话术别用。
6. **诚实**:永远别打包票"这条会爆"。爆不爆还看表情、剪辑、发布时间、算法、运气——文案只是一部分。

## 🧠 写之前先过脑(爆款心理学,来自 IP 方法论)
详见 `references/IP方法论精要.md`。快速版:
- **爆款选题 = 老问题 + 新情绪 + 强代入感。**
- 一个选题要过三关:**情绪启动(唤起)→ 冲突张力(停留)→ 角色代入(锁定)**。
- **利他 = 有效给予**:先想"这条说给谁?他最焦虑/最不解什么?他要被安抚还是要方法?"

## 🔄 两个入口

### 入口 A:类型 + 话题 → 5 型框架
读 `references/5型生成框架.md`,选型 → 先问缺的要素(或用创作者默认)→ 按结构写。
对照同型样本节奏(`references/爆款样本原文/`)。

### 入口 B:"看到什么说什么" → 把素材总结成口播
用户甩来一条新闻/观察/吐槽/热点 →
①扒人性内核(底下是人的什么在起作用)②找反转角度(大家想 A,你偏说 B)③套结构、落回价值观。

**输出格式(两个入口都一样)**:`1 条正文(150–260 字) + 3 个备选开头 + 1 句金句`。

## 5 型速查(详见 `references/5型生成框架.md`)
| 型 | 什么时候用 | 结构 |
|---|---|---|
| ①故事叙事型 | 讲一个人/事带出观点 | 矛盾引子→反转→对比→小故事→金句 |
| ②知识讲解型 | 给判断/方法(分点) | 矛盾引子→反转认知→分点3-5→举例→金句 |
| ③心态启发型 | 心法/价值观/反焦虑 | 悬念引子→心态反转→案例→升华→金句 |
| ④情感走心型 | 温度/共鸣 | 生活矛盾→反思→细节故事→升温→金句 |
| ⑤混合型 | 大主题全都要 | 矛盾引子→故事→分点→心态升华→金句 |

## 开头怎么写
优先:反常识断言 / 痛点反问 / 场景代入 / 人群圈定 / 情感共鸣。
弹药库:`references/开头钩子库.md`、`references/100条开头钩子.md`(借结构,别抄叫卖味)。
**蹭流量公式**:【正在爆的热点】+【一个反常识的点】→ 拐回你的主题。
> ⚠️ 蹭之前先核实热点"当下真在爆"、戏名/人名/事实对不对(可用 WebSearch)。拿不准先问创作者,别猜。

## 常见坑(别踩)
1. 没设人设就硬写 → 出来的口播没人味,像通稿。**先填 6 个空。**
2. 写太书面 → 用创作者的口语。
3. 开头太软 → 头一句就上冲击。
4. 打包票会爆 → 别,诚实讲"更有机会"。
5. 蹭错热点 → 先核实,拿不准先问。
6. 停在"讲道理/教方法" → 一定要落回人性。
