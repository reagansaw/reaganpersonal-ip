# 爆款拆解 · 5 大套路模板

拆自雷哥给的 5 条爆款。**关键结论:它们没有一条靠"干货"火,靠的是"情绪 + 认知反转 + 排比金句 + 共情"。**
雷哥要做的,就是把这套结构,嫁接到"AI + 道法自然"上——借 AI 说人生、说焦虑、说认知。

## 爆款的 6 条铁律(先背下来)
1. **开头别自我介绍**。5 条爆款没有一条"大家好我是XX"开场,全是直接讲故事 / 代入反问 / 抛断言。
2. **先接情绪,再讲道理**。永远先站到观众那一边,替他共情、替他说话。
3. **排比金句是命**。每条爆款都有一段"你怕A是因为B,你怕C是因为D"式排比——这是记忆点,也是转发点。
4. **要有具体的人和场景**。设计系女生、教爸妈用 WhatsApp、见客户战战兢兢……越具体越可信。
5. **认知反转**。把一个被误解的事翻过来看(00后看钱=懂钱;被孤立≠你的错;不怕失去=值钱)。
6. **升华金句收尾**。最后一句要能被截图、能当签名。

## 套路 A｜故事共情式(拆自「00后看钱」)
> 替一个群体/观众正名,打共鸣。
- **骨架**:最近跟某人聊天 → 抛出一个被误解的现象 → 我不反驳,讲个反例案例 → 排比翻案 → 反问升华
- **原文**:跟做广告老板聊天 → 他说00后太看钱 → 我想起设计系女生被画饼、跳槽翻倍 → "你说他们太犀利,可他们只是知道情怀不能当饭吃,承诺不能抵房租" → "他们要的,是不是其实只是他们应得的?"
- **雷哥套用**:#6 不用AI就被淘汰这句话怎么吓唬你、#38 焦虑贩子想卖你课 → 见 `成品/示例04`

## 套路 B｜悬念清单式(拆自「女人围着转」)
> 干货、方法论,带点争议。
- **骨架**:反问抛悬念"为什么…" → 承诺给 N 个点 → 逐条拆(可对话体) → 金句收尾
- **原文**:为什么有些男人不帅不有钱女人却围着转 → "4 种生理欲望" → 逐条 → "知己知彼,百战不殆"
- **雷哥套用**:#20 让AI干活前先想清楚这三个问题、#25 用AI之前先过这三关

## 套路 C｜开悟排比式(拆自「不怕失去就值钱」)★最适合雷哥
> 认知、心法、道法自然。
- **骨架**:我在某刻想通一件事 → 抛反直觉观点 → 排比戳痛点(你怕X是因为Y) → 亲身案例 → 一个可执行的小动作 → 升华金句
- **原文**:21岁开悟 → "学会不怕失去就能提升价值" → "你怕老板是因为怕失业,你怕客户是因为怕丢单" → 见客户从战战兢兢到不卑不亢 → 默念"我不需要从他身上得到什么" → "当你能接受失去任何东西,你才配得起拥有真正的一切"
- **雷哥套用**:#46 道法自然用在AI上啥意思、#42 AI让努力贬值让判断升值 → 见 `成品/示例05`

## 套路 D｜今昔对比催泪式(拆自「对父母没耐心」)
> 价值观、温度、情感。
- **骨架**:代入反问"你有没有发现你会…" → 具体场景 → 今昔对比(当年他们…如今我们…) → 排比 → 情感升华 → 行动指引
- **原文**:你有没有对爸妈没耐心 → 教他们用WhatsApp → "当年你学走路跌倒100次,他们没嫌你;如今他们慢一点,你却嫌他们笨" → "他们能问你的日子,真的不多了"
- **雷哥套用**:可写"我们被效率追着跑,却忘了慢下来"这类反效率焦虑的温度内容

## 套路 E｜痛点反转治愈式(拆自「职场被孤立」)★很适合反焦虑
> 反焦虑、安顿人心。
- **骨架**:痛点断言"其实要毁掉一个人很简单" → 列举场景 → 共情"你开始怀疑自己" → 反转"这些想法全错了,是内耗" → 数字清单方法 → 治愈升华
- **原文**:职场搞垮一个人很简单 → 打招呼装没看到、下午茶跳过你 → "你开始怀疑自己" → "这些想法全是错的,是内耗" → 3个生存法则 → "活成一个安静有光但不张扬的人"
- **雷哥套用**:#31 别慌你没那么容易被淘汰、#33 越焦虑越乱学 → 见 `成品/示例03`

## 排比金句公式(直接套 AI 版)
爆款的转发点全在排比。记住这几个句式,填 AI 的内容进去:

- **「你怕 X,是因为你怕 Y」×3** → 收束本质
  - AI 版:"你焦虑 AI,不是因为它太强,是因为你还没想清自己强在哪。"
- **「你说他们 A,可他们只是 B」×N**
  - AI 版:"你说他们只会用 AI,可他们只是不想把命,浪费在重复上。"
- **「它能 A,却 B」对仗反转**
  - AI 版:"AI 能帮你写得更快,帮不了你想得更清;能帮你做得更多,帮不了你做得更对。"
- **「A 不能当饭吃,B 不能抵房租」具象排比**
  - AI 版:"工具不能替你思考,效率不能替你判断。"
- **「不是 A,是 B」认知反转句**
  - AI 版:"AI 取代的不是人,是没在动脑子的那部分动作。"
