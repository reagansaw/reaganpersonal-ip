# IP 方法论精要（给学生打底）

> 提炼自两份学员手册。写口播前,先懂这些底层逻辑,不然只会套模板、不会自己想。

## 一、先分清:网红 / 博主 / IP / 人设
- **网红**:求"红",拼注意力的广度。来得快去得快。
- **博主**:交"友",平起平坐分享,松弛感。
- **IP**:立"信"——**你能实实在在影响别人某一类决策的能力**。拼影响力的深度,赚长钱。
- **人设**:不是编剧本,是观众看完你一条条内容后,**在心里攒出来的印象**。

> 记住:网红比谁认识我的人多,IP 比谁信我的判断、愿意跟着我走。

## 二、做 IP = 构建三层壁垒
1. **强实践(最高级)**:你真干成过事、真踩过坑、真拿到结果 → 说的话自带分量,别人抄不走。
2. **强立场 + 强专业(次级)**:
   - 强立场:爱恨分明,敢替一部分人说话 → 给人**归属感**("这人跟我一头的")。
   - 强专业:一个领域啃透,有自己一套方法论、标签化观点 → 给人**确定性**。
3. **做一个真人(最终)**:主标签(专业)+ 小爱好小脾气小缺点。有血有肉才可亲。

## 三、现在做 IP 还来得及吗?
来得及。玩套路、博眼球的那波泡沫退了,才轮到有真东西的人。
未来**永不饱和**的三类 IP:①真能解决问题的实干型 ②真能安顿人心的陪伴型(不搞噱头不制造恐慌)③真能接续文化的文化型。
> 小成靠术,大成靠德。别追算法,先修自己。别贪快,要贪久。

## 四、选题底层逻辑:爆款的本质是心理学
爆款不是算法推的,是**观众用潜意识投票**的结果。一个选题要成立,过三关(心理闭环):
1. **情绪启动点(唤起)**:头 3 秒能不能勾起情绪?(焦虑/羞耻/愤怒/心疼)没"感"就划走。
2. **冲突张力(停留)**:有没有悬而未解的张力?(现实 vs 期待 / 我 vs 外界 / 欲望 vs 满足)
3. **角色代入(锁定)**:他会不会觉得"这说的就是我"?(用人群标签圈定)

**五个爆款心理驱动力**:①生存焦虑 ②群体对比 ③价值冲突 ④情绪自证(帮他确认想法没错)⑤共鸣认同(你是我同类)。

**爆款选题公式:老问题 + 新情绪 + 强代入感。**
> 例:老问题"职场怎么相处"→ 加情绪"为什么你越帮忙越被瞧不起"→ 加人群"打工人怎么设边界不被 PUA"。

**让观众感同身受的三个动作**:①视角转换(从"我想说"→"他想听")②价值匹配(情绪/方法/转发,至少占一个)③结构转化(把"我的经历"→"一句可复用的认知")。

## 五、利他 = 有效给予(不是自我感动)
你以为的利他是"给干货",但用户可能只想吃麦当劳,你却递阳春面。
**四大投射(别踩)**:①认知投射(以为他懂你懂的)②价值观投射(以为你的观点代表大众)③情绪投射(只顾发泄)④经验投射(把你的经历当通用模板)。
**正确姿势**:定位他者(精准描述他的心理状态)→ 理解处境(他最焦虑/最不解/最不服什么)→ 输出匹配(他要被安抚?被理解?要方案?)。

## 六、终极护城河:做真正的自己
- **稳定内核**(永不变):你最稳的价值观、人格、主导动机。
- **流动外壳**(随便变):表达形式、当下情绪、平台。
> IP 的第一性原理是"心智凝结"——用户心里对你稳定一致的认知(如:王老吉=怕上火)。这不是演出来的,是长出来的。

## 七、半年翻盘(顺便修自己)
身体(管作息运动)→ 注意力(拒绝信息垃圾)→ 死磕一项技能 → 换一轮身边人。
> 你常接触的 5 个人,决定你的状态和收入。
