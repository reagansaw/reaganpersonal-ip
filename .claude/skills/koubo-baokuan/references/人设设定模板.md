# 人设设定模板（学生第一次用先填这个）

> 通用版口播 skill 唯一需要你"填空"的地方。填一次,以后每条口播都照这个来。
> 填得越具体,出来的口播越像"你",越不像 AI 通稿。

## 你的 6 个空
1. **你是谁**(一句话身份):____
   例:一个做了 10 年的健身教练 / 一个二胎宝妈 / 一个开小吃店的老板娘

2. **你的赛道**(你专讲什么):____
   例:健身减脂 / 育儿 / 餐饮创业 / 两性关系 / 玄学

3. **你帮谁**(目标观众,越具体越好):____
   例:30 岁产后想瘦下来、又没时间的妈妈(不是"想减肥的人")

4. **你的核心观点 / 反差**(你跟同行不一样在哪):____
   例:"别人教你狠练,我教你先别练" / "我做玄学,但我不吓唬你"

5. **你的语言风格**:____
   例:马来西亚接地气口语(见 `马来西亚口语.md`)/ 标准华语口语 / 台味 / 港味

6. **你的口头禅 / 签名结尾**:____
   例:"我是 XX,我们下条见" / "记住,别急"

---

## 填完的例子(可参考)
1. 你是谁:一个做了 12 年的中医推拿师
2. 赛道:颈椎腰椎、久坐痛
3. 帮谁:天天对电脑、脖子硬得像石头的打工人
4. 核心反差:"别一痛就去按摩,越按可能越糟"
5. 语言:大马口语
6. 签名:我是陈师傅,痛,先别忍。

> 把你的 6 个空填好,交给 skill,它就用**你的人设**来写,而不是套别人的。
